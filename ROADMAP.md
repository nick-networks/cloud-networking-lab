# Roadmap

Each phase is a GitHub milestone. Each lab or study task is an issue on the Projects board.

| Milestone | Covers | Done when |
| --- | --- | --- |
| M0 Repo setup | Structure, README, templates, CI, security settings | Repo public, CI green |
| M1 Networking fundamentals | Subnetting, TCP/IP, DNS, BGP basics | Notes written in `notes/fundamentals` |
| M2 AWS core networking | Labs 01 to 10 (NextWork VPC series) | Ten labs merged with diagrams |
| M3 Advanced and hybrid | Labs 11 to 14, built in Terraform | Transit Gateway and VPN labs working |
| M4 Certification | Cert to be chosen (AWS Cloud Practitioner is the natural first step) | Exam passed, badge added |
| M5 Capstone | Multi-VPC hub-and-spoke project | Project in `projects/`, featured in README |
| M6 Second cloud | Azure equivalents | Optional, after M4 |

## Weekly rhythm

- Sunday: pick this week's issues and move them to **Up next**.
- Each finished lab is a pull request that closes its issue.
- End of each milestone: a short retro in the milestone description.
